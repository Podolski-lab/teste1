- (decision) Modo de trabalho: Coaching path. Propósito: build-substrate (Claude implementa o produto para o usuário) + artefato visual adicional no Finalize (deck/HTML) para entendimento do usuário e apresentação a terceiros.
- (constraint) Restrição de plataforma confirmada via pesquisa web: Skill customizada da Alexa NAO pode abrir microfone/esperar resposta proativamente sem sessão iniciada pelo usuário. Reminders API é mão-única (só fala). Mecanismo viável: Custom Tasks integradas a Alexa Routines - routine dispara Custom Task, que abre sessão real de diálogo (pergunta/espera/retry). Fontes: developer.amazon.com docs Proactive Events, Alexa Reminders, Manage Skill Sessions, Custom Triggers for Routines, Integrate Custom Task with Alexa Routines.
- (direction) Caminho proposto: Rotinas de horario fixo (resumo semanal sexta 18h/domingo 20h) disparam Custom Task diretamente. Rotinas de horario dinamico (lembrete/checkpoint por tarefa, dependente do Google Calendar) usam Custom Triggers for Routines, disparados programaticamente pelo backend na hora certa. Requer setup manual do usuario no app da Alexa (criar as Rotinas uma vez) - gap novo em relacao ao PRD/UX, que so previa config manual de pilares no backend.
- (decision) Hospedagem: Lambda auto-gerenciado (nao Alexa-hosted Skill) - precisa de EventBridge Scheduled Rule proprio para o polling, que Alexa-hosted pode nao permitir com liberdade total.
- (decision) Linguagem: Node.js (ASK SDK v2) - caminho mais documentado/maduro para Alexa Custom Skills.
- (decision) Agendamento dinamico: polling periodico (Lambda em cron via EventBridge Scheduled Rule, ex. a cada 10min) le o Google Calendar e dispara Custom Trigger quando alguma tarefa esta na hora - preferido a agendamento dinamico por evento (over-engineering pro caso), consistente com a tolerancia de atraso ja documentada no FR-1 do PRD.
- (decision) Armazenamento: DynamoDB - mapeamento pilar/proposito por evento (FR-11), historico de checkpoints, dados do resumo semanal. Par padrao com Lambda no free tier da AWS.
